# money-transfer-system

v1 Создал структуру User с перечисленными полями, реализовал два метода один для зачисление, другой для вычета.
Создал двух пользователей user проверил работу двух методов вывел результат в консоль
v2 Создал структуры PaymentSystem и Transaction, реализовал методы добавления пользователей и транзакций, а также обработку переводов между пользователями с проверкой существования пользователей и достаточности средств. Добавил несколько транзакций в очередь и обработал их поочерёдно через for.
v3 Добавил конкурентную обработку транзакций: реализовал Worker, передачу транзакций через буферизованный канал, запуск нескольких горутин и ожидание их завершения через sync.WaitGroup. Также проверил программу через go run -race . и обнаружил data race при одновременном изменении баланса пользователей.
